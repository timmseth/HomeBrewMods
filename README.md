# HomeBrewMods

Mods I make for the games I play, sorted by game, game version and mod loader:

```
<Game>/<game version>/<loader>/<Mod name>/<modid>-mc<game version>-<loader><loader version>-<mod version>.jar
```

## Minecraft

| Game version | Loader | Mods |
|---|---|---|
| 26.2 | Fabric 0.19.5 | [WorldBound family](Minecraft/26.2/Fabric): Earth Data World Gen, Earthish World Gen, Earth / Earthish Fossil Record, Earth / Earthish Landmarks, TATV |

Each mod's folder has its jar and a README with what it does and how to install it. Source code is in each loader
folder's `_source`.
